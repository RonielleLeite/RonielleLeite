## 🚀 Sobre Mim

Sou um desenvolvedor focado em criar soluções eficientes, interfaces modernas e aplicações com regras de negócio sólidas. Com forte base em Engenharia de Software, transito entre o desenvolvimento de front-ends ricos e a lógica de programação em linguagens estruturadas e orientadas a objetos.

📍 Localizado em **Volta Redonda - RJ, Brasil**, busco sempre desafios e oportunidades para gerar impacto com código limpo e boas práticas.

## 💼 O Que Faço

- **Desenvolvimento Frontend**: Criação de interfaces modernas, reativas e responsivas com Angular 17+, Vue.js, React e JavaScript moderno.
- **Lógica & Engenharia**: Desenvolvimento estruturado e orientado a objetos com Java, C e C++.
- **Design System & UX/UI**: Aplicação de padrões visuais consistentes, micro-interações e responsividade mobile-first com CSS3 e Bootstrap.
- **Persistência & Estado**: Gestão de dados em tempo real no cliente com Web Storage API (`localStorage`) e integração com bancos relacionais (MySQL / PostgreSQL).

## 🌟 Projetos em Destaque

### 🏨 [Bela Vista Hotel & Resort (Carro-Chefe)](https://github.com/RonielleLeite/hotel-bela-vista)
> **Aplicação Web Completa de Hospitalidade de Luxo com Motor de Reservas e Painel da Gerência em Tempo Real.**

* **Para o Hóspede:** Consulta dinâmica de vagas, validação de datas no front-end, cálculo automático de noites/diárias e modal de checkout com simulação de pagamento (Pix/Cartão).
* **Para a Gerência:** Portal administrativo protegido com cards de faturamento acumulado, diárias vendidas, controle de check-in e cancelamentos sincronizados via `localStorage`.
* **Design & UX:** Design System exclusivo (`:root`), tipografia nobre, 100% responsivo com menu hambúrguer animado.

**Tecnologias**: HTML5 Semântico • CSS3 Moderno • JavaScript ES6+ • Web Storage API • GitHub Pages
